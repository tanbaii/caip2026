# FAQ：被骗后应该如何处理？

## 问题

如果不幸遭遇电信网络诈骗，受害者应该采取哪些紧急措施来减少损失并配合警方追查？

## 详细答案

### 第一步：立即止损（黄金30分钟）

#### 1.1 紧急联系银行

**目标**：阻止资金继续转出或尝试撤销转账

- **拨打银行客服电话**：立即拨打银行卡背面的官方客服热线，申请：
  - 临时冻结账户（口头挂失）
  - 尝试撤销转账（如果是通过网银转账且未到账单可尝试）
  - 查询资金流向，记录对方收款账户

- **主要银行客服电话**：
  | 银行 | 客服电话 |
  |------|----------|
  | 中国工商银行 | 95588 |
  | 中国农业银行 | 95599 |
  | 中国银行 | 95566 |
  | 中国建设银行 | 95533 |
  | 交通银行 | 95559 |
  | 招商银行 | 95555 |
  | 中国邮政储蓄银行 | 95580 |

- **通过ATM输错密码锁卡**：如果附近刚好有该银行的ATM，可故意连续输错三次密码，临时锁卡（仅适用于借记卡）。

#### 1.2 紧急联系第三方支付平台

如果通过支付宝、微信支付等第三方平台转账：
- 支付宝：拨打95188，申请投诉举报并尝试撤回
- 微信支付：拨打95017，申请投诉举报
- 在APP内找到对应交易记录，点击"投诉""举报"或"对订单有疑问"

#### 1.3 冻结对方账户（通过警方）

- 立即拨打110或96110报警
- 向警方提供：转账时间、转账金额、对方账户（银行卡号/支付宝账号/微信账号）
- 警方可通过"电信网络新型违法犯罪交易风险事件管理平台"向银行发送紧急止付指令
- 银行接到指令后应当立即冻结相关账户

### 第二步：保存证据

#### 2.1 通信记录证据

| 证据类型 | 保存方法 |
|----------|----------|
| 通话记录 | 截图通话时间、号码、时长；如有录音一并保存 |
| 短信记录 | 截图全部短信内容，不要删除 |
| 微信/QQ聊天记录 | 截图对话内容；导出完整聊天记录；保存对方账号信息 |
| 邮件记录 | 截图邮件内容，保存发件人邮箱地址 |

#### 2.2 资金交易证据

| 证据类型 | 保存方法 |
|----------|----------|
| 银行转账记录 | 截图网银/手机银行转账记录；到银行柜台打印交易流水 |
| 第三方支付记录 | 截图支付宝/微信/云闪付等交易详情页 |
| ATM转账凭条 | 保留纸质凭条，拍照备份 |
| 现金存款凭条 | 保留纸质凭条，拍照备份 |

#### 2.3 其他证据

- **对方提供的链接/二维码**：不要点击，但截图保存链接地址或二维码图片
- **对方发送的APP**：保留安装包或下载链接，不要卸载（供警方技术鉴定）
- **对方发送的文件/图片**：全部保存，不要删除
- **虚假合同/协议**：如有，保留原件或清晰照片

#### 2.4 证据保存注意事项

- **不要清理手机**：不要删除聊天记录、短信、通话记录
- **不要恢复出厂设置**：这会清除所有证据
- **多设备备份**：将截图、照片备份到云端或其他设备，防止手机损坏或丢失
- **记录时间线**：整理一份事件时间线，记录每一次接触的时间、方式、内容

### 第三步：正式报警

#### 3.1 报警渠道

| 渠道 | 联系方式 | 适用情况 |
|------|----------|----------|
| 110 | 电话拨打 | 紧急报警，任何诈骗案件 |
| 96110 | 电话拨打 | 反诈专线，专业咨询和举报 |
| 属地派出所 | 现场报案 | 需要制作笔录、提交证据 |
| 网络违法犯罪举报网站 | www.cyberpolice.cn | 在线举报网络诈骗 |
| 国家反诈中心APP | APP内举报 | 便捷举报，可上传证据图片 |

#### 3.2 报案时需要提供的信息

- **受害者基本信息**：姓名、身份证号、联系电话
- **被骗经过**：详细描述诈骗过程的时间线
- **转账信息**：转账时间、金额、方式（网银/ATM/第三方支付）、对方账户信息
- **对方信息**：对方电话号码、社交账号、自称身份、网站/APP名称
- **已采取措施**：是否已联系银行、是否已尝试撤回转账
- **证据材料**：聊天记录截图、转账记录、通话记录等

#### 3.3 报案回执

- 要求公安机关出具《受案回执》或《立案回执》
- 记录案件编号和办案民警联系方式
- 询问案件进展查询方式

### 第四步：配合调查

#### 4.1 如实陈述

- 如实向警方陈述被骗经过，不要隐瞒或夸大
- 即使涉及个人隐私（如裸聊敲诈），也要如实说明，警方会保护隐私
- 提供所有掌握的证据材料

#### 4.2 技术鉴定配合

- 如需对手机、电脑进行技术鉴定，配合警方封存设备
- 如需对涉案APP、网站进行鉴定，提供下载来源和使用过程

#### 4.3 资金追踪

- 警方立案后会通过"电诈平台"追踪资金流向
- 如资金已转移到多级账户，追踪需要时间
- 保持与办案民警的联系，及时了解进展

### 第五步：后续处理

#### 5.1 资金返还

- 如警方成功冻结涉案资金，会按照《电信网络新型违法犯罪案件冻结资金返还若干规定》办理返还
- 需要配合提供身份证明、银行卡信息等材料
- 返还程序可能需要较长时间，需耐心等待

#### 5.2 民事诉讼

- 如已知诈骗分子身份信息（极少数情况），可另行提起民事诉讼
- 但多数电信网络诈骗犯罪分子在境外或身份虚假，民事诉讼难以执行
- 建议以刑事追赃为主要途径

#### 5.3 心理疏导

- 遭遇诈骗后可能会感到自责、羞耻、焦虑
- 记住：诈骗分子是专业团队，受害者没有过错
- 如需心理帮助，可拨打心理援助热线或寻求专业心理咨询

#### 5.4 防止二次诈骗

- 警惕"网警""黑客""律师"声称能帮你追回钱款，要求先付费的，都是二次诈骗
- 只有公安机关有权办理追赃，且不会收取任何费用
- 资金返还只能通过公安机关办理，不要轻信任何"收费追赃"的承诺

## 紧急处理流程图

```
发现被骗
    ↓
【立即行动】← 黄金30分钟
    ↓
拨打银行客服 → 申请冻结/撤销
    ↓
拨打110或96110 → 报警并提供对方账户
    ↓
保存所有证据 → 截图、备份、不删除
    ↓
到派出所做笔录 → 获取案件回执
    ↓
配合警方调查 → 保持联系
    ↓
等待追赃结果 → 警惕二次诈骗
```

## 法律依据

- 《中华人民共和国刑事诉讼法》第一百一十条：报案、控告、举报
- 《中国银监会 公安部关于印发电信网络新型违法犯罪案件冻结资金返还若干规定的通知》
- 《中国人民银行关于加强支付结算管理防范电信网络新型违法犯罪有关事项的通知》：紧急止付和快速冻结机制
