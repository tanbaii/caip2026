# 反欺诈知识库总览

## 知识库概述

本知识库为反欺诈AI问答系统（RAG）提供结构化、高质量的知识支撑，涵盖法律法规、诈骗类型、诈骗话术、风控规则、常见问答五大维度。所有文档均经过法律准确性校验和RAG检索优化，可直接用于Embedding索引和混合检索。

## 知识库结构

```
knowledge_base/
├── README.md                          # 本文件：知识库总览与使用指南
├── laws/                              # 法律法规（共25个文件）
│   ├── 中华人民共和国刑法相关条文（7个）
│   ├── 中华人民共和国反电信网络诈骗法
│   ├── 司法解释（3个）
│   ├── 行政法规与部门规章（4个）
│   └── 其他相关法律（10个）
├── fraud_types/                       # 诈骗类型（9个文件）
├── fraud_rules/                       # 结构化风控规则（9个JSON文件）
├── fraud_scripts/                     # 诈骗话术库（9个文件）
└── faq/                               # 常见问答（4个文件，持续扩充）
```

## RAG检索策略建议

### 检索配置

| 参数 | 建议值 | 说明 |
|------|--------|------|
| Chunk Size | 512-1024 tokens | 法律条文保持条款完整性 |
| Chunk Overlap | 128-256 tokens | 保证上下文连贯 |
| Top-K 检索 | 5-10 | 混合检索后去重 |
| 相似度阈值 | 0.65-0.75 | 过滤低质量匹配 |

### 混合检索权重

建议采用以下混合检索策略：

| 检索通道 | 权重 | 适用场景 |
|----------|------|----------|
| Dense Embedding（语义检索） | 0.5 | 理解用户意图，匹配语义相近内容 |
| BM25（关键词检索） | 0.3 | 精确匹配法律术语、法条编号 |
| Structured Rule Matching | 0.2 | 直接命中风控规则 |

### 多路召回策略

1. **法律问答**：优先检索 `laws/` 和 `faq/`
2. **诈骗识别**：优先检索 `fraud_types/`、`fraud_rules/`、`fraud_scripts/`
3. **应急处置**：优先检索 `faq/` 中的紧急应对文档
4. **综合咨询**：全库检索，按相关性排序

### Rerank优化

建议使用Cross-Encoder对初筛结果进行重排序：
- 训练数据：反诈领域问题-文档对
- 输入：用户Query + 候选Chunk
- 输出：相关性分数
- Top-N截取：重排序后取Top-5

## 引用规范

所有知识库文档在生成回答时，应遵循以下引用规范：

1. **法律引用格式**：《法律名称》第X条
2. **司法解释引用格式**：《解释名称》第X条
3. **规则引用格式**：规则ID（如S001）
4. **类型引用格式**：诈骗类型名称（类型ID）

示例：
> 根据《中华人民共和国刑法》第二百六十六条，诈骗公私财物数额较大的，处三年以下有期徒刑。同时依据反诈规则S001（刷单返利），该行为具有"要求先转账后返利"的危险信号。
