# FAQ：如何识别电信网络诈骗？

## 问题

普通用户如何在日常生活中识别电信网络诈骗？有哪些通用的识别方法和预警信号？

## 详细答案

### 一、通用识别原则（"十个凡是"）

凡是遇到以下情况，极大概率是诈骗：

1. **凡是"公检法"要求转账的** —— 公检法机关绝不会通过电话、网络要求转账汇款到"安全账户"。凡是接到自称公安、检察院、法院的电话要求转账的，都是诈骗。

2. **凡是刷单返利的** —— 所有要求先垫资、后返利的"兼职""刷单"都是诈骗。正规兼职不会让你先交钱。

3. **凡是通知中奖但要先交费的** —— 中奖信息本身是诱饵，要求先缴纳"税费""保证金""手续费"才能领奖的，都是诈骗。

4. **凡是声称"零门槛""无抵押"贷款的** —— 要求先交"保证金""解冻费""手续费"才能放款的，都是诈骗。

5. **凡是自称领导、熟人要求转账的** —— 收到领导、朋友、家人的转账请求，一定要通过电话或其他方式二次确认，不要仅凭QQ、微信消息就转账。

6. **凡是通知"涉案"要求配合调查的** —— 真正的执法机关不会通过电话办案，更不会要求你下载远程控制软件或转账验资。

7. **凡是索要银行卡密码、验证码的** —— 银行工作人员、客服绝不会通过电话、短信索要你的密码、验证码。凡是索要这些信息的，都是诈骗。

8. **凡是投资"保本高收益"的** —— 承诺"稳赚不赔""内幕消息""高回报零风险"的投资理财项目，基本都是诈骗。

9. **凡是通知快递丢失要赔偿的** —— 正规快递公司不会通过私人电话或社交软件处理理赔，更不会要求你点击链接填写银行卡信息。

10. **凡是陌生链接要求填写个人信息的** —— 不要点击来历不明的链接，不要在陌生网站填写身份证号、银行卡号、密码、验证码等敏感信息。

### 二、风险信号识别清单

#### 通信渠道风险

| 风险信号 | 说明 |
|----------|------|
| 境外来电 | +号开头或00开头的境外号码，如无境外关系，直接挂断 |
| 陌生短信含链接 | 不要点击短信中的任何链接 |
| 社交软件陌生人搭讪 | 主动搭讪的"美女""帅哥""投资导师"多为诈骗 |
| 频繁更换联系方式 | 诈骗分子常频繁更换电话号码、社交账号 |

#### 资金操作风险

| 风险信号 | 说明 |
|----------|------|
| 要求向私人账户转账 | 正规机构不会要求向个人账户转账 |
| 要求分多笔转账到不同账户 | 诈骗分子为逃避监测常要求分散转账 |
| 要求购买虚拟货币转账 | 虚拟货币交易难以追踪，是诈骗常用手段 |
| 要求通过第三方平台转账 | 绕过正规支付渠道的转账要求需警惕 |

#### 心理操控手段

| 操控手段 | 诈骗话术示例 | 应对方法 |
|----------|-------------|----------|
| 制造紧迫感 | "限时操作""账户即将冻结""不办理就扣款" | 冷静下来，通过官方渠道核实 |
| 制造恐惧感 | "你涉嫌洗钱""不转账就要逮捕你" | 挂断电话，拨打110核实 |
| 制造贪婪感 | "限时高收益""内部消息""稳赚不赔" | 牢记"天上不会掉馅饼" |
| 制造权威感 | "我是公安局的""这是国家项目" | 要求对方提供工号，通过官方渠道回拨核实 |
| 制造亲近感 | "老同学，帮我个忙""领导急需用钱" | 通过电话或见面确认对方身份 |

### 三、技术验证方法

#### 视频通话验证

当对方声称是熟人或领导要求转账时：
- 要求视频通话，观察对方面部表情是否自然
- 让对方用手遮挡面部再移开（AI换脸可能被识破）
- 问一个只有你们知道的私密问题

#### 信息核验

- 通过官方渠道（官网、官方客服电话、官方APP）核实信息
- 不要回拨对方提供的电话，自己查找官方电话拨打
- 通过"国家反诈中心"APP的"身份核验"功能核实对方身份

#### 链接和APP验证

- 安装"国家反诈中心"APP，开启来电预警和APP自查功能
- 对陌生链接使用杀毒软件扫描
- 不安装来历不明的APP，特别是对方发送的链接中的APP

### 四、特殊场景识别

#### 冒充客服类

- 电商客服：通过官方APP联系客服核实订单状态
- 快递客服：通过官方渠道查询物流信息
- 银行客服：拨打银行卡背面的官方客服电话

#### 虚假投资类

- 查询平台是否有金融监管部门颁发的牌照
- 在中国证监会、银保监会官网查询平台资质
- 警惕"保本高收益"承诺，正规投资不会承诺保本

#### 网络交友类（杀猪盘）

- 对方过于完美或感情进展过快需警惕
- 不久就提到"赚钱""投资""副业"的，基本都是诈骗
- 拒绝见面或视频通话的，身份可疑

- 《中华人民共和国广告法》第二十五条：招商广告不得承诺保本收益
