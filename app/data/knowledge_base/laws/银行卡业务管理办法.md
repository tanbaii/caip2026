# 银行卡业务管理办法

## 立法信息

- **发布机关**：中国人民银行
- **发布时间**：1999年1月5日
- **施行时间**：1999年3月1日
- **文号**：银发〔1999〕17号

---

## 第一章 总则

### 立法目的

为加强银行卡业务的管理，防范银行卡业务风险，维护商业银行、持卡人、特约单位及其他当事人的合法权益，依据《中华人民共和国中国人民银行法》、《中华人民共和国商业银行法》、《中华人民共和国外汇管理条例》及有关行政法规制订本办法。

### 银行卡定义

本办法所称银行卡，是指由商业银行（含邮政金融机构，下同）向社会发行的具有消费信用、转账结算、存取现金等全部或部分功能的信用支付工具。

### 银行卡分类

| 分类标准 | 类型 | 功能特点 |
|----------|------|----------|
| 清偿方式 | 信用卡 | 具有透支功能 |
| | 借记卡 | 先存款后使用，不具有透支功能 |
| 发行对象 | 个人卡 | 面向个人发行 |
| | 单位卡 | 面向企业、机关、团体等发行 |
| 币种 | 人民币卡 | 以人民币结算 |
| | 外币卡 | 以外币结算 |
| | 双币种卡 | 兼具人民币和外币账户 |

## 第二章 银行卡的发行与账户管理

### 开户实名制要求

#### 第二十八条 个人卡申领

个人申领银行卡（储值卡除外），应当向发卡银行提供公安部门规定的本人有效身份证件，经发卡银行审查合格后，为其开立记名账户。

凡在中国境内金融机构开立基本存款账户的单位，应当凭中国人民银行核发的开户许可证申领单位卡。

#### 实名制在反诈中的意义

银行卡实名制是防范电信网络诈骗的第一道防线：
- 确保每张银行卡都能追溯到真实持卡人
- 防止犯罪分子批量购买、租用他人银行卡用于转移赃款
- 为公安机关追查资金流向提供线索

### 账户数量限制

#### 同一客户持卡数量

同一客户在同一商业银行开立借记卡原则上不得超过4张（社会保障卡、医疗保险卡、军人保障卡、已销户借记卡除外）。

同一代理人在同一商业银行代理开立借记卡原则上不得超过3张。

### 异常开户识别

商业银行应当建立异常开户监测机制，对以下情形加强审核：
- 批量开户或代理开户数量异常的
- 开户理由不合理或明显超出正常需求的
- 陪同他人集中开户的
- 拒绝提供必要身份信息或提供虚假信息的
- 开户后立即开通大额网银支付、手机银行等功能的

## 第三章 银行卡的交易与结算

### 转账限额管理

#### 个人银行账户分类管理

| 账户类型 | 功能 | 限额 |
|----------|------|------|
| I类户 | 全功能账户，存款、购买理财、转账、消费缴费、支取现金 | 无额度限制 |
| II类户 | 存款、购买理财、限额消费缴费、限额向非绑定账户转出资金 | 日累计1万元，年累计20万元 |
| III类户 | 限额消费缴费、限额向非绑定账户转出资金 | 账户余额上限2000元，日累计2000元，年累计5万元 |

### 交易监测

商业银行应当建立银行卡交易监测系统，对以下异常交易进行监测和预警：
- 短期内资金分散转入、集中转出或集中转入、分散转出
- 资金快进快出，不留余额或留下一定比例余额后转出
- 账户频繁接收与自身职业、收入明显不符的大额资金
- 账户在异地、境外频繁发生交易
- 账户被多次用于向不同被害人接收小额资金后集中转出

## 第四章 银行卡的风险管理

### 持卡人风险防范义务

#### 密码保护

持卡人应当妥善保管银行卡和密码，不得将密码告知他人。因持卡人泄露密码或未尽到防范义务造成的损失，由持卡人自行承担。

#### 挂失义务

持卡人发现银行卡遗失、被盗或密码泄露，应当立即向发卡银行办理挂失手续。挂失手续办妥前发生的损失，由持卡人承担（但因银行过错造成的除外）。

### 银行安全保障义务

#### 身份验证

发卡银行应当采用安全的身份验证方式，包括但不限于：
- 静态密码
- 动态验证码（短信验证码）
- 数字证书
- 生物识别技术（指纹、人脸）

#### 风险提示

发卡银行应当在以下环节向持卡人进行风险提示：
- 开通网上支付、手机支付功能时
- 进行大额转账时
- 账户发生异常交易时
- 向可疑账户转账时

### 伪卡交易与盗刷责任

#### 责任划分原则

发生伪卡盗刷交易或者网络盗刷交易，持卡人请求发卡行承担责任的，人民法院应予支持：
- 发卡行未能识别伪卡或未能验证真实身份导致盗刷的，承担全部责任
- 持卡人未尽到妥善保管密码等义务的，可适当减轻发卡行责任
- 持卡人未及时挂失导致损失扩大的，对扩大部分自行承担责任

## 第五章 银行卡在电信网络诈骗中的涉罪情形

### 情形一：出售、出租、出借银行卡

#### 行为表现

- 将自己名下的银行卡出售给诈骗团伙
- 出租银行卡供他人使用并收取"租金"
- 出借银行卡给"朋友"用于"走账"

#### 法律后果

- **行政处罚**：根据《中国人民银行关于加强支付结算管理防范电信网络新型违法犯罪有关事项的通知》，5年内暂停其银行账户非柜面业务、支付账户所有业务，并不得新开立账户。
- **刑事责任**：
  - 明知他人用于实施电信网络诈骗而出售银行卡 → 诈骗罪共犯
  - 明知他人利用信息网络实施犯罪而提供支付结算帮助 → 帮助信息网络犯罪活动罪（刑法287条之二）
  - 情节严重标准：出售5张以上，或支付结算金额20万元以上

### 情形二："跑分"洗钱

#### 行为表现

- 通过个人银行卡为诈骗团伙接收赃款
- 将赃款分散转入多张银行卡（"拆账"）
- 通过ATM取现或第三方支付转移赃款

#### 法律后果

- **掩饰、隐瞒犯罪所得罪**：明知是犯罪所得而予以转移、窝藏
- **帮助信息网络犯罪活动罪**：为网络犯罪提供支付结算帮助
- **诈骗罪共犯**：与诈骗分子事前通谋的

### 情形三：冒用他人银行卡

#### 行为表现

- 捡拾他人银行卡后冒用
- 通过非法手段获取他人银行卡信息后盗刷
- 骗取他人银行卡及密码后使用

#### 法律后果

- **信用卡诈骗罪**：使用伪造、骗领、冒用的信用卡，或恶意透支
- **盗窃罪**：盗窃他人银行卡并使用的
- **诈骗罪**：骗取他人银行卡及密码后使用的

## 第六章 持卡人遭遇诈骗后的救济

### 紧急止付

持卡人发现被骗后，应当立即：
1. 拨打银行客服电话申请临时冻结账户
2. 拨打96110反诈专线报警
3. 通过银行APP或网银尝试撤销转账（如支持）

### 快速冻结

公安机关接到电信网络诈骗报案后，应当立即通过"电信网络新型违法犯罪交易风险事件管理平台"向银行发送冻结指令，银行应当在接到指令后即时冻结相关账户。

### 资金返还

对已明确权属的被骗资金，公安机关应当按照《中国银监会 公安部关于印发电信网络新型违法犯罪案件冻结资金返还若干规定的通知》办理资金返还。
